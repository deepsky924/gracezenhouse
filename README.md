# Grace Zen House — gracezenhouse.com

Static multi-page site, generated by a dependency-free Node script.

```bash
npm run dev     # build + serve http://localhost:4321, rebuilds on change
npm run build   # write ./dist
docker build -t gracezenhouse . && docker run --rm -p 8080:80 gracezenhouse
```

## Where things live

| Path | What |
|---|---|
| `src/data.mjs` | All business content: contact info, services, prices, Square booking links, reviews, owner bio |
| `build.mjs` | Page templates, meta/OG/canonical tags, JSON-LD, sitemap, dev server |
| `src/assets/` | `styles.css`, `main.js` (progressive enhancement only), self-hosted `fonts/` (latin subset) |
| `src/public/` | Copied to the site root: favicon, `og-image.png` (source: `src/og-image.svg`) |
| `nginx.conf` | Serving, `/health`, 301s from retired pages of the old site |

## Deploying on Cloudflare

Pages: build command `node build.mjs`, output directory `dist`, env `NODE_VERSION=24`.
The build writes `dist/_redirects` (301s from the old site's URLs) and `dist/_headers`
(security + asset caching), which Cloudflare Pages and Workers static assets both read.
The redirect list lives in `build.mjs`; keep `nginx.conf` in step if Coolify stays in use.

## Before launch

- **Owner name & credentials** — placeholders in `owner` in `src/data.mjs` (set `isPlaceholder: false` once filled; placeholders render highlighted).
- **Photos** — every `ph(...)` call in `build.mjs` is a sized placeholder labelled with the intended shot. Replace with `<img>` (4:5 portrait or 3:2 landscape).
- **Analytics** — set `site.analytics.plausibleDomain` in `src/data.mjs`; every booking link then reports a `Book` event with the service name.
- **Search Console** — set `site.googleSiteVerification`, deploy, verify, then submit `https://gracezenhouse.com/sitemap.xml`.
- **Deep facial pages** — eight facials have only a summary and benefits; richer owner-written detail (steps, prep, aftercare) will help them rank.
- **Treatment durations** — add `duration: '60 min'` (etc.) to each facial in `src/data.mjs`; it then shows beside every price and in the booking panel.
- **Cancellation policy** — once confirmed, add it to `reassurance` in `src/data.mjs` so it appears beside every Book button.
- **First-visit practicalities** — add `[title, text]` pairs to `visitNotes` in `src/data.mjs` (arrival time, parking, what to wear for Reiki, rescheduling). They appear in "Your visit" on every service page.
- **Years of experience** — the About bio shows a highlighted `[over a decade — confirm years]` placeholder until confirmed.
